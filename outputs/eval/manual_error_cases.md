# 人工抽样复核错误案例

评估时间：2026-06-11  
样本来源：`outputs/eval/eval_manual_sample.csv`，共 20 条公告级样本  
复核依据：`outputs/extract_results/records_validated.csv`、`data/pdf/*.pdf`、`data/parsed/*.md`

## 1. 样本范围混入普通公司债

涉及样本：

| doc_id | 债券 | 问题 |
|---|---|---|
| `02279a1b64687f35` | 22万科 05 | 公司债发行人赎回选择权，不属于可转债强赎 |
| `00d8ff93ff716bce` | 23重发 01 | 公司债发行人赎回选择权，不属于可转债强赎 |
| `0fb9af5c0fca7685` | 21建房01 | 公司债发行人赎回选择权，不属于可转债强赎 |
| `1f12792e645893ca` | 23广资01 | 公司债发行人赎回选择权，不属于可转债强赎 |

建议：在正式可转债评估中增加范围过滤，要求债券简称或公告正文明确包含“转债/可转换公司债券”，普通公司债赎回选择权单独归档或剔除。

## 2. 代码字段误填

样本：`0fb9af5c0fca7685`，21建房01  
模型值：`stock_code=149539`  
人工判断：公告无股票代码，`149539` 是债券代码，应保留 `stock_code=null`。  
建议：公司债样本不得用债券代码回填股票代码；正式保存前增加 `stock_code != bond_code` 的规则检查。

## 3. 日期字段误抽

样本：`03f93945dfe5ccba`，家联转债  
模型值：`last_convert_date=2026-05-28`  
人工判断：PDF正文写明“可转债最后转股日：2026年5月27日”，`2026-05-28` 是赎回日。  
建议：强赎实施公告中区分 `最后转股日`、`赎回登记日`、`赎回日`、`摘牌日`，不要用相邻日期互相回填。

## 4. 历史价格混入当前事件

样本：`09d83a9026b8effd`，龙大转债  
模型值：`original_conv_price=9.30`、`new_conv_price=4.20`、`effective_date=2026-02-12`  
人工判断：该公告是 2026-05-06 的董事会提议向下修正公告，尚未披露本次修正后价格；上述价格和生效日来自公告中“转股价格调整情况”的历史记录。  
建议：下修提议阶段只记录当前转股价和触发阈值；`new_conv_price`、`effective_date` 应留空，直到决议或实施公告披露。

## 6. 证据文本不足

涉及样本：

| doc_id | 债券 | 问题 |
|---|---|---|
| `1b9272a66b161a74` | 宏图转债 | `evidence_text` 仅含标题，不能支撑修正前后价格和生效日 |
| `20c3a35eac0b5974` | 利柏转债 | `evidence_text` 仅为日期，不能支撑预计触发赎回条件 |
| `09d83a9026b8effd` | 龙大转债 | 证据文本把当前提议与历史下修价格混在一起 |

建议：每个关键字段的证据文本应包含对应字段值本身，至少覆盖代码、事件阶段、核心日期、核心价格或触发阈值。
